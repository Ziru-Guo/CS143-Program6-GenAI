# CS143-Program6-GenAI
# Contact Book
## problem
The problem that we want AI to write a solution to is the simple console-based Contact Book in Java.
The program should use Object-Oriented Programming (a `Contact` class) and a `HashMap` to store and look up contacts quickly by name. It should allow the user to:
- Add a new contact (name and phone number)
- Search for a contact by name
- Delete a contact by name
## Reflection
With such approach I managed to get an idea of how to split coding prompt in several specific prompts in order to teach AI to code one step at a time instead of asking for everything to be done. It also allowed me to recall how classes and objects as well as the implementation of HashMap in Java interact and allow to quickly save and retrieve data.
Speaking of pros and cons of the development process, it becomes obvious that the key advantage of collaboration with GenAI is speed - just within few minutes I received a basis for contact book. At the same time, GenAI can be too simplistic as for the initial draft – there are edge cases missing, e.g., duplicates or empty input – which should be considered and discussed explicitly.
