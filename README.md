# CS143-Program6-GenAI
# Contact Book
# problem
The problem that we want AI to write a solution to is the simple console-based Contact Book in Java.
The program should use Object-Oriented Programming (a `Contact` class) and a `HashMap` to store and look up contacts quickly by name. It should allow the user to:
- Add a new contact (name and phone number)
- Search for a contact by name
- Delete a contact by name
